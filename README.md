# Tally Toolkits - Windows download

Download the installer for Tally Toolkits (Windows 10/11, x64):

**[TallyToolkitsSetup.exe](https://github.com/kalaione/tally-toolkits-download/releases/latest/download/TallyToolkitsSetup.exe)**

- Installs per-user; no admin rights or UAC prompt.
- Internet is needed once to activate the PC.
- This build is unsigned, so Windows SmartScreen may ask you to confirm:
  **More info -> Run anyway**.

Tally Toolkits is a launcher for TallyPrime, TallyPrime Edit Log and
Tally.ERP 9. Your Tally data stays on your PC.
